# Заряженная скалярная чёрная дыра: исправленная задача раздела 2.6

## 1. Постановка

Рассматривается метрика

$$
ds^2=e^{2F(r)}f(r)dt^2-\frac{dr^2}{f(r)}-r^2d\Omega^2
$$

и вещественная амплитуда заряженного комплексного скалярного поля $\psi$.
Электромагнитные переменные обозначены $\tau$, $\mu$. Радиус
неэкстремального горизонта выбран единицей. Параметры:

$$
e>0,\qquad m>0,\qquad \alpha\in\mathbb R,\qquad \beta\ge0.
$$

Аудит исходного вывода приведён в
[`CSF2023-06-12-review.md`](CSF2023-06-12-review.md).

## 2. Дифференциальная система

Состояние

$$
y=(f,\psi,v,\tau,\mu),\qquad v=\psi'.
$$

Правая часть сохраняет структуру (2.29)–(2.32):

1. (2.29) решается относительно $f'$;
2. (2.32) решается относительно $\tau'$;
3. вычисляется $F'$ из (2.25);
4. (2.30), (2.31) решаются как линейная система для $(\psi'',\mu')$.

Это позволяет независимо вычислять невязки исходных уравнений и обнаруживать
вырождение производного блока. При $\beta=0$ реализована отдельная система
(2.33)–(2.36), используемая как регрессионная проверка.

## 3. Горизонт

Пусть $x=r-1$. Для устранения формальных $0/0$ вводятся

$$
f=x\widehat f,\qquad \tau=x\widehat\tau.
$$

Регулярный ряд строится рекуррентно до $x^8$. Первые коэффициенты:

$$
f_1=1-(m^2+\mu_h^2)\psi_h^2,\qquad \tau_1=\mu_h,
$$

$$
\psi_1=
\frac{\psi_h[m^2-(1+\alpha e)\mu_h^2]}
{f_1(1-\beta\mu_h^2)}.
$$

Требуются $f_1>0$, $1-\beta\mu_h^2\ne0$, $\psi_h>0$, $\mu_h>0$.
В граничных данных адаптивно используются порядки 5–7. Следующий коэффициент
оценивает ошибку; если она не меньше $0.1\,\mathtt{bc\_tol}$, $\varepsilon$
уменьшается.

## 4. Бесконечность

Исправленная асимптотика:

$$
\psi\sim pe^{-mr}r^{-1-Mm}
\left(1+\frac{a_1}{r}+\frac{a_2}{r^2}+\frac{a_3}{r^3}+\cdots\right),
$$

$$
\tau\sim qe^{-gr}r^{s_\tau}
\left(1+\frac{b_1}{r}+\frac{b_2}{r^2}+\frac{b_3}{r^3}+\cdots\right),
\qquad \mu\sim\tau',
$$

$$
g=\sqrt{m^2+\frac{e^2+2\alpha e m^2}{1+\beta m^2}}-m>0.
$$

Для метрики

$$
f=1-\frac{2M}{r}+\cdots,\qquad F(\infty)=0.
$$

На конечной границе используются два асимптотических порядка, третий
контролирует выбор $r_{\max}$.

## 5. Метод

Основной метод — адаптивная коллокация `scipy.integrate.solve_bvp`. При
фиксированных $e,m,\beta,\psi_h$ вместе с профилем уточняются
$\mu_h,\alpha,M$. Амплитуды $p,q$ определяются в том же решении устойчивой
линейной оценкой по парам $(\psi,\psi')$ и $(\tau,\mu)$ в хвосте.

На правой границе используются эквивалентные Robin-условия

$$
\psi'-L_\psi(r_{\max})\psi=0,\qquad
\mu-L_\tau(r_{\max})\tau=0,
$$

где логарифмические производные $L_\psi,L_\tau$ вычисляются из ряда второго
порядка без экспоненциального множителя. Это устраняет потерю ранга Якобиана,
когда сами хвосты меньше машинного масштаба. Общий производный блок
нормируется построчно до проверки числа обусловленности.

| Настройка | Значение |
|---|---:|
| `tol` | $10^{-7}$ |
| `bc_tol` | $10^{-9}$ |
| максимум узлов | 50 000 |
| начальное $\varepsilon$ | $10^{-3}$ |
| начальное $r_{\max}$ | 20 |

Для трудных стартов доступна адаптивная гомотопия от гладкого согласованного
профиля к полной нелинейной системе. Первичный атлас можно выполнять с
`--disable-homotopy`; такие отказы остаются `numerically_unresolved` и могут
быть повторены с гомотопией посредством `--retry-invalid`.

Различные корни ищутся детерминированным multistart и классифицируются по
$(n_\psi,n_\tau)$. Найденные точки сначала продолжаются по $\psi_h$, затем
по $\beta$ с адаптивным шагом. При отказе обычного шага после двух точек
используется секущее pseudo-arclength-условие в
$(\psi_h,\mu_h,\alpha,M)$.

## 6. Критерии конфигурации

Конфигурация публикуется как статическая сферически-симметричная
асимптотически плоская неэкстремальная чёрная дыра, только если:

- $f'(1)>0$, $f(r)>0$ во внешней области;
- поля и производный блок конечны;
- хвосты согласованы с исправленными рядами;
- максимальная нормированная невязка не превышает $10^{-6}$; сырая невязка
  сохраняется отдельно;
- наблюдаемые устойчивы к уточнению на уровне $10^{-5}$.

Проверка устойчивости обязательна: повторный solve использует меньший
$\varepsilon$, больший $r_{\max}$ и более строгие допуски. Непрошедшая её
точка не попадает в `configurations.jsonl`.

Сохраняются $\alpha,\beta,e,m,\psi_h,\mu_h,f'(1),F_h,M,p,q,g$,
поверхностная гравитация, числа узлов и численные невязки.

## 7. Запуск только через локальный `.venv`

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[test]"
```

Одиночное приближение:

```bash
.venv/bin/python -m numerical_solutions charged-black-hole solve \
  --charge 1 --scalar-mass 1 --beta 0 --psi-h 0.3
```

Демонстрационный атлас:

```bash
.venv/bin/python -m numerical_solutions charged-black-hole atlas
```

Результаты записываются в игнорируемый каталог
`results/charged-black-hole/`. `configurations.jsonl` является источником
для CSV и Markdown; области без найденного корня записываются в
`invalid-regions.jsonl`. Лучший отклонённый кандидат каждой обследованной
ячейки записывается в `best-candidates.jsonl`, а его сетка и пять полей — в
`candidate-profiles/<candidate-id>.npz`. Эти записи диагностические и не
смешиваются с опубликованными конфигурациями.

Для каждой неразрешённой ячейки сохраняются точные границы, Sobol-seed,
узловая маска, число стартов, настройки решателя, распределение типов отказов
и лучшая достигнутая глобальная невязка. Для аварийного `solve_bvp` это
максимум RMS-невязки по всем интервалам и нормированной граничной невязки,
а не минимум по отдельному удачному интервалу. В JSON явно записывается тип
метрики, исходный старт, параметры последней итерации и ссылка на профиль.
Совпадение старой записи проверяется по версии уравнений и полному fingerprint
настроек.

## 8. Проверки CI

Отдельный обязательный job `symbolic-verification`:

- независимо строит точный горизонтный ряд до $x^8$;
- подставляет его во все (2.29)–(2.32), проверяет отсутствие полюсов,
  зануление коэффициентов и ожидаемый первый остаток;
- портит контрольный коэффициент каждого поля и требует ненулевой остаток;
- независимо строит правые коэффициенты до $r^{-3}$;
- проверяет геометрию, сферическую редукцию и точный предел $\beta\to0$;
- сравнивает независимые коэффициенты с runtime-рекурсией.

## 9. Ограничения

- Атлас конечен и не доказывает полноту множества решений.
- `numerically_unresolved` не означает математического несуществования.
- Раздел 2.6 задаёт условия чёрной дыры. Кротовые норы и голые сингулярности
  требуют другой краевой постановки.
- Старые Fortran-ряды относятся к регулярному центру, а не горизонту; они
  использованы только как ориентир по порядку разложения.
